# Day 1 — YOLOv8 Person Detection Pipeline

## Overview
This is the first module of the Retail Brain OS project.

The system performs real-time person detection on CCTV/store video footage using YOLOv8 and OpenCV.

---

## Features
- Video input support
- Real-time person detection
- Bounding box visualization
- CCTV video processing
- YOLOv8 integration

---

## Tech Stack
- Python
- YOLOv8 (Ultralytics)
- OpenCV
